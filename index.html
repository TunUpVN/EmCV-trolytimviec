Hồ sơ gốc

Claude chỉ dùng những gì ghi ở đây để viết CV, không tự thêm kinh nghiệm. Ghi càng cụ thể (số liệu, kết quả) thì CV càng mạnh.

Tiêu chí tìm job

Nút "Tìm job bằng Claude" ở mục Job dùng các tiêu chí này để tìm tin tuyển dụng mới trên web.

Cách dùng AI

Sao chép prompt: mỗi lần chấm điểm, viết CV hay tìm job, app soạn sẵn yêu cầu để bạn dán vào khung chat AI, rồi dán câu trả lời ngược lại. Không cần API key.

Kết nối Claude API

App gọi thẳng Claude API bằng API key của bạn. Key chỉ lưu trong trình duyệt này (localStorage), không gửi đi đâu ngoài api.anthropic.com. Lấy key tại console.anthropic.com; mỗi lần chấm điểm, viết CV hay tìm job sẽ tính phí theo bảng giá API.

Sao lưu dữ liệu

Toàn bộ job, hồ sơ và tiêu chí chỉ nằm trong trình duyệt này. Xóa dữ liệu trình duyệt hoặc đổi máy sẽ mất, nên thỉnh thoảng hãy xuất file sao lưu.
